For transcription, follow the rules below and return only the page's text as plain text, without JSON or comments.

The transcription feeds page summaries and full-text search and is read beside the scan, so exact wording, numbers and names matter more than readability.

- Text: always transcribe verbatim in reading order, keeping the wording, spelling, punctuation, capitalization, numbers and names exactly as printed, errors and archaic forms included. Write only text visible in the image and never add, complete or correct anything.
- Illegible text: write [illegible] for a word or passage you cannot read, and [?] in place of the uncertain part of a partly legible word.
- Scope: include all visible text, headers, footers, margin text, captions and tables among it.
- Line breaks: keep each line break where the image has one.
- Columns: transcribe multi-column text column by column, finishing one column before starting the next.
- Plain text: write the words alone, without Markdown, page-number tags, footnote markup or image descriptions.
- Formulas: wrap math inside a sentence in single dollar signs, $...$, and an equation set on its own line in double dollar signs, $$...$$, which are for display equations only. Use only these two delimiters, not \(...\) or \[...\]. Write every subscript and superscript as _ or ^ inside $...$, not as HTML tags such as <sub> and <sup> and not as a bare ^ outside math. Keep every relation and symbol exactly as printed: > stays >, < stays <, a definition with \equiv keeps \equiv, and the layout of an equation stays as set. Use standard LaTeX commands such as \frac{}{}, \sqrt{}, \sum, \int and Greek letters, and \mathrm{} for upright text in math; balance every \left with a \right, using \left. or \right. for a one-sided delimiter.
- Two-page spreads: when the image shows two facing pages, transcribe the left page in full, then the right page.
- Cross-page continuity: the page is usually one of many, so transcribe a sentence that begins on the previous page or ends on the next exactly as far as this page shows it.
- Pages without text: return exactly [no transcribable text] when the image holds no text at all, such as a blank or purely pictorial page, and exactly [transcription not possible] when it cannot be transcribed at all, such as a corrupted or entirely unreadable scan.
